01 / The point

Linux-like where useful.
Windows where essential.

01

Native where it matters

Explorer owns the taskbar, Start, Search, tray, clock, multi-monitor behavior, and fullscreen handoff. Snap handles exact half-screen layouts.

02

Unix where it helps

Windows Terminal opens one clear UCRT64 Bash profile with Git, Neovim, Yazi, tmux, Starship, and familiar command-line tools.

03

Explicit, reversible control

Preview first. Choose optional apps yourself. Keep rollback data. Aggressive cleanup and performance policies stay separate and opt-in.

02 / Ongoing control

One panel.
No background panel.

Workstation App Control lives in the Start menu and runs only when you open it. Search installed apps, stop known background activity, remove startup entries, launch registered uninstallers, or inspect process memory without being bounced through several Settings pages.

  • Installed apps and uninstall actions
  • Reversible startup disable and restore
  • Live process memory and guarded process ending

The panel does not silently block an app you launch yourself. Persistent blocking is a separate, explicit policy.

03 / Less machinery

What the standard profile retires.

It removes the project hooks that caused duplicate bars, stolen shortcuts, startup popups, fullscreen conflicts, and terminal sprawl. Third-party apps are only uninstalled when you choose them.

GlazeWM + ZebarWindows Snap + Explorer taskbar

No always-on tiling manager or replacement dock is required.

Win-key hooksNative Start and Search

Win opens Start. Win + S opens Search.

Many terminal entriesOne visible UCRT64 profile

PowerShell 7 remains available for native administration.

Global startup allowlistExplicit blocklists only

Unlisted apps are preserved. Removal remains a deliberate choice.

05 / Reversible by design

Know the change before it happens.

  1. 01Preview

    Run the installer with -WhatIf.

  2. 02Choose

    Keep, disable, or uninstall optional apps.

  3. 03Back up

    Capture values before supported changes.

  4. 04Apply

    Use the standard profile first.

  5. 05Verify

    Check taskbar, Snap, startup, and drift.

  6. 06Roll back

    Use the matching rollback command.

Aggressive profiles stay opt-in.

Machine-wide cleanup and performance tuning are hardware-specific. They require review, elevation, and separate confirmation; some Windows servicing operations only have best-effort rollback.

07 / Before you run it

Straight answers.

Do I launch the installer every time?

No. The installer configures the workstation once. Workstation App Control remains available from Start for ongoing app, startup, and process management.

Will this replace or cover the Windows taskbar?

No. The standard profile retires the old custom-bar hooks and restores Explorer's native taskbar, including normal fullscreen behavior.

Will the Windows key and half-screen Snap work?

Yes. The standard profile restores native Start and enables Windows Snap. Use Win + Left/Right for monitor halves and Win + Z for layouts.

Does it uninstall Overwolf or other apps automatically?

No. The default is keep. You must explicitly choose disable-at-startup or uninstall, either in the guided installer or App Control.

Is this Linux, WSL, or a virtual machine?

No. Windows remains the only operating-system kernel. The project adds a Unix-like command-line environment without installing WSL or a VM.
