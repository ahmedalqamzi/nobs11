03 / Pick your line

Three profiles.
No hidden escalation.

The downloaded installer explains the boundary before it changes anything. Lean is recommended for most systems; Maximum is the hardware-sensitive reference profile.

STANDARDFix the experience

Native taskbar, Start, Snap, clean terminal setup, rollback data, and NoBS11 Control. No cleanup policy.

LEAN / RECOMMENDEDCut user-level overhead

Adds reviewed current-user cleanup and performance settings without removing optional Windows apps or disabling machine services.

MAXIMUM / REFERENCEGo after the full result

Adds optional app and component removal plus elevated service, task, and performance changes. Requires explicit typed confirmation and UAC.

EVERY PROFILESecurity stays on

Defender, VBS and mitigations, Windows Update, Store, WinGet, drivers, and gaming essentials are deliberately preserved.

04 / Ongoing control

One app.
Only when you open it.

NoBS11 Control lives in the Start menu and closes when you close its window. Search installed apps, stop known background activity, remove startup entries, run registered uninstallers, or inspect live process memory without bouncing through several Settings pages.

  • Installed-app search and in-app uninstall actions
  • Reversible startup disable and restore
  • Live process memory and guarded process ending

Disabling background activity removes known automatic launch sources and stops the current process. It does not prevent you or another app from launching it later.

08 / Straight answers

Before you run it.

Do I run the installer every time Windows starts?

No. Installation is one-time. NoBS11 Control remains in Start for ongoing app, startup, and process management, and it only runs while its window is open.

Can everyone reach 7 GB idle RAM?

No. The ~7 GB result came from one 64 GB reference laptop using its final configuration. Your drivers, hardware tools, Windows build, startup apps, and chosen profile determine your result.

Will it break the taskbar, Windows key, Snap, or games?

The project deliberately uses Explorer's native taskbar and Windows Snap, removes the old replacement-bar and key-hook machinery, and preserves normal fullscreen handoff. Maximum still requires hardware and game validation because its machine policy is aggressive.

Does it uninstall Overwolf or other apps automatically?

The guided app choices default to keep. You must explicitly choose disable-at-startup or uninstall. Maximum separately warns that its reviewed Windows optional-app policy is broader.

Is NoBS11 Linux, WSL, or a replacement operating system?

No. It is a Windows performance toolkit. Optional Unix-style command-line tools are included for people who want them, but Windows remains the only operating-system kernel.
